# AI Voice Assistant

A production-grade AI voice assistant with speech-to-text, conversational memory, and text-to-speech — powered by OpenAI Whisper, GPT-4o-mini, and TTS.

---

## How It Works

1. User clicks the mic and speaks
2. Audio is sent to FastAPI, transcribed via OpenAI Whisper
3. Transcript is sent to a LangGraph agent with PostgreSQL checkpointing for persistent memory
4. Answer is generated by GPT-4o-mini with full conversation history
5. Answer is converted to speech via OpenAI TTS and played back automatically

---

## Stack

| Layer | Technology |
|-------|-----------|
| Speech to Text | OpenAI Whisper |
| LLM | OpenAI gpt-4o-mini |
| Text to Speech | OpenAI TTS (alloy voice) |
| Agent Framework | LangGraph |
| Memory | PostgresSaver (PostgreSQL) — persists conversation across sessions via thread_id |
| Backend API | FastAPI |
| Frontend UI | Streamlit |
| Deployment | Docker Compose |

## Setup

### 1. Clone the repo

```
git clone https://github.com/MSaiRam10/AI-Voice-Assistant.git
cd AI-Voice-Assistant
```

### 2. Create a .env file

```
OPENAI_API_KEY=your_openai_key
DATABASE_URL=postgresql://postgres:password@db:5432/voiceassistant
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=your_langsmith_key
LANGCHAIN_PROJECT=ai-voice-assistant
```

### 3. Run with Docker

```
docker-compose up --build
```

Open your browser at `http://localhost:8504`

---

## Usage

1. Click the microphone button and speak
2. The assistant transcribes your speech, thinks, and responds
3. The response is played back as audio automatically
4. The assistant remembers previous messages in the conversation
